Emby Backup

Full backups of Emby's server data and databases. Movie metadata, artwork, NFO files, cache, logs, transcodes and media folders are never included.

Settings

The archive is uploaded as .partial, renamed, and followed by its .sha256 file. Verifying an FTP archive downloads it to a temporary file first.
Automatic backups run every day at 03:00 (server local time).
Network and FTP passwords, and the optional backup password, are saved in plugins/configurations/EmbyBackup.xml as plain text. Use a dedicated account with access only to the backup destination.

Restore from a backup

Reads the archive from the destination configured above.
You will be asked to confirm twice. Emby keeps the current plugin settings and does not delete files created after the backup.

A restore replaces Emby's server configuration and databases with the contents of the archive while Emby keeps running, then asks you to restart Emby. Files created after the backup are not deleted, and the current destination and credentials are kept. You can also stop Emby, extract the ZIP directly into the program data folder (it has no extra root folder), and start Emby. Use Verify before restoring.
